# -Arogyasathi-Smart-Medical-Assistance-and-Predictive-HealthCare-System-
Smart Health Prediction Using Machine Learning – Arogyasathi: A healthcare application that predicts possible diseases based on symptoms provided by the patient. It uses the Naive Bayes Classifier to generate disease probability and provides features such as doctor search, appointment booking, chat consultation, and PDF report generation.
Arogyasathi – Smart Medical Assistance and Predictive Healthcare System

Project Description:
A web-based healthcare system that predicts possible diseases from user symptoms using Machine Learning and provides basic healthcare assistance.

Features:

* Symptom-based disease prediction
* Skin disease detection using images
* Patient, Doctor and Admin modules
* Doctor consultation and chat
* Appointment booking
* Health suggestions and prediction reports

Tech Stack:
Python, Flask, HTML, CSS, JavaScript, Scikit-learn, Machine Learning, SQL/Database

How to Run:

1. Clone the repository.
2. Install the required Python dependencies.
3. Run the Flask application.
4. Open the local URL in a web browser.

Screenshots:
Home Page, Login Page, Disease Prediction Page, Results Page and Admin Dashboard.
